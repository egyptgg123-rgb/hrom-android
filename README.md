# Хром — личный голосовой ИИ-ассистент для Android

Говоришь «Хром, включи не беспокоить» или «Хром, напиши маме в Telegram, что в 10 буду дома» — и он делает.
Устроен так: **микрофон → распознавание речи → ИИ (любая модель через OpenRouter) решает, что делать → Хром нажимает кнопки и запускает функции телефона → отвечает голосом**.

Всё собирается в облаке через GitHub Actions, компьютер не нужен.

---

## 1. Залить проект на GitHub (с телефона, через Termux)

1. На GitHub создай **пустой** репозиторий `hrom-android` (без README).
2. В Termux:

```bash
pkg update && pkg install -y git unzip
termux-setup-storage
cd ~
unzip /sdcard/Download/hrom-android.zip
cd hrom-android
git init -b main
git add .
git commit -m "Хром: первая версия"
git remote add origin https://github.com/ТВОЙ_НИК/hrom-android.git
git push -u origin main
```

(Для пароля при push используй Personal Access Token, как в других твоих проектах.)

## 2. Собрать APK

После push сборка стартует сама: репозиторий → вкладка **Actions** → **Build APK**.
Когда станет зелёной, открой её и внизу в **Artifacts** скачай `hrom-debug-apk`. Внутри `app-debug.apk`. Установи его (разреши установку из браузера/файлов).

Если сборка красная: открой упавший шаг, скопируй текст ошибки и отправь Claude. Проект писался без возможности скомпилировать его на месте, поэтому первая сборка может потребовать одной-двух мелких правок.

## 3. Первый запуск

1. Открой приложение **Хром**.
2. Нажми **«Разрешения»** и разреши всё (микрофон, контакты, звонки, SMS, уведомления).
3. Нажми по очереди остальные кнопки доступов и включи Хром в открывшихся настройках:
   - **Служба доступности** — главное. Это «руки»: через неё Хром читает экран и нажимает кнопки в Telegram и любых других приложениях.
   - Доступ к уведомлениям, «Не беспокоить», системные настройки (яркость), поверх других окон (чтобы Хром мог открывать приложения из фона), без ограничений батареи.
4. Введи **ключ OpenRouter**, нажми **«Найти бесплатные модели»**, выбери одну и нажми **«Сохранить настройки»**.
5. Нажми **«Запустить Хрома»**. В шторке появится уведомление «Хром на связи».
6. Скажи: «Хром, который час?» (или нажми «Слушать сейчас» и говори без слова активации).

### Если «Служба доступности» серая и не включается
Android 13+ блокирует такие права у приложений, установленных не из магазина. Открой кнопкой **«Информация о приложении»** → меню ⋮ в углу → **«Разрешить ограниченные настройки»** → подтверди. После этого вернись и включи службу.

### Ключ и модель (OpenRouter)
1. Зарегистрируйся на openrouter.ai, открой **Keys** и создай ключ (`sk-or-...`). Вставь его в приложение и нажми «Сохранить настройки». Ключ хранится только на телефоне и в репозиторий не попадает.
2. Нажми **«Найти бесплатные модели»**: приложение само спросит у OpenRouter, какие модели сейчас бесплатные и умеют вызывать функции. Тапни любую, и она выберется.
3. Хочешь умнее: впиши в поле «Модель» любой id с openrouter.ai/models (например `vendor/name`). Платные модели потребуют пополнить счёт OpenRouter.

**Про бесплатные модели честно:** они слабее платных и хуже справляются с цепочками шагов (открыть Telegram, найти чат, написать, отправить). Простые команды («включи фонарик», «не беспокоить», «будильник на 7») обычно проходят. У бесплатных есть дневные и минутные лимиты, поэтому при ошибке 429 подожди или выбери другую модель из списка. Список меняется со временем, это нормально. Если модель ошибается, попробуй следующую: для этого проекта важнее всего умение вызывать функции.

## Что умеет Хром (54 функции)

**Приложения и интернет:** открыть любое приложение, список приложений, открыть ссылку, поиск в Google, загрузить страницу или API (погода, курсы), открыть раздел настроек, страница приложения (остановить/очистить).

**Звук, свет, режимы:** «Не беспокоить» (вкл/только будильники/тишина/выкл), громкость любого потока, режим звонка, яркость, фонарик, плитки быстрых настроек (Wi-Fi, Bluetooth, данные, авиарежим, геолокация и т.д.), управление музыкой (пауза, дальше, назад, громкость), вибрация.

**Информация:** заряд батареи, дата и время, какое приложение сейчас открыто.

**Время и планы:** будильник, таймер, напоминание голосом через N минут, событие в календаре, маршрут в картах.

**Связь:** звонок, завершить и принять звонок, SMS, чтение входящих SMS, поиск контакта, WhatsApp (чат с готовым текстом), Telegram (открыть чат и написать), «поделиться» текстом в любое приложение.

**Устройство:** камера (фото/видео), буфер обмена, чтение и очистка уведомлений, включить экран, сказать вслух, подождать.

**Руки (управление любым экраном):** прочитать экран, нажать по тексту, нажать/долго нажать в точку, свайп, прокрутка, ввести текст, системные кнопки (назад, домой, недавние, шторка, меню питания, блокировка, скриншот).

**Память:** запомнить факт («мама» = контакт «Мама»), вспомнить, забыть; рутины: «Хром, запомни рутину „спокойной ночи“: включи не беспокоить, убавь яркость, поставь будильник на 7» — и потом одной фразой.

Всё остальное Хром собирает из этих кусочков сам: например, «закажи такси» — открыть приложение, прочитать экран, нажимать шаг за шагом.

## Честные ограничения

- **Разблокировать телефон Хром не может.** Android не даёт приложениям вводить PIN и пароль за тебя. Экран должен быть разблокирован (или без пароля).
- **Права нужно выдать вручную один раз.** Служба доступности, «Не беспокоить» и остальное включаются тобой в настройках: обойти это нельзя ни одному приложению.
- **Интерфейс чужих приложений меняется.** Нажатия по тексту («Отправить», «Send») могут сломаться после обновления Telegram. Хром читает экран и пробует другой путь, но 100% гарантии нет.
- **Банки, платежи и защищённые экраны** часто запрещают чтение и нажатия через службу доступности. Это защита самих приложений.
- **Слово «Хром» ловит стандартное распознавание Google.** Оно иногда ошибается и может на секунду пищать при перезапуске. Если мешает, выключи «Слушать слово активации всегда» и пользуйся кнопкой «Слушать» в уведомлении или плиткой в шторке.
- **Постоянное прослушивание расходует батарею**, а на некоторых прошивках (Xiaomi, Huawei, Samsung) их «оптимизатор» убивает фоновые сервисы. Отключи ограничение батареи для Хрома и закрепи приложение в недавних.
- **После перезагрузки** телефона Android 14 запрещает стартовать микрофону сам. Придёт уведомление «Нажми, чтобы запустить», один тап — и Хром работает.
- **Нужен интернет**: «думает» Хром в облаке. Бесплатные модели могут отвечать медленнее и иногда недоступны.

## Безопасность

- Хром спрашивает голосовое подтверждение перед оплатой, переводами, покупками и удалением данных.
- Текст с экрана, из SMS, уведомлений и сайтов считается данными, а не командами: Хром не выполняет инструкции, найденные там.
- Пароли на экране скрываются, коды и PIN Хром не зачитывает и не вводит.
- Служба доступности — очень мощное право. Ставь Хром только из своей сборки и никому не передавай ключ OpenRouter.

## Структура проекта

```
.github/workflows/build.yml          сборка APK в облаке
app/src/main/java/com/hrom/assistant/
  MainActivity.kt                    главный экран: доступы, ключ, запуск, тест
  VoiceService.kt                    фоновое прослушивание и слово «Хром»
  Brain.kt                           связь с OpenRouter, цикл «подумал → сделал → проверил»
  Tools.kt                           все 54 функции телефона
  HromAccessibilityService.kt        «руки»: чтение экрана, нажатия, ввод
  HromNotificationListener.kt        чтение уведомлений
  Receivers.kt                       напоминания, запуск после перезагрузки, плитка в шторке
  Speaker.kt, Prefs.kt, Util.kt      голос, настройки, мелочи
```

Чтобы добавить новое умение: опиши его в `buildDefs()` и добавь ветку в `run()` в `Tools.kt` — ИИ начнёт им пользоваться сам.
